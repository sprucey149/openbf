# Retired loop prompt

The unattended launcher and its scheduler have been retired. This path remains as
an entry point for older links; Git history preserves the former standing prompt.

Use the build, review and land brief templates in `docs/agents/brief.md` and the
standing rules in `AGENTS.md`. GitHub issues hold the public work list and ownership.
Archived technical records preserve evidence without reserving work or accepting
unfinished gameplay.

When investigating something observed in play, read the F9 black box snapshot
first. `analysis/dev-tools.md` documents its bots, sound and damage records.
